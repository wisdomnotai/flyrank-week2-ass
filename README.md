# Task API

A simple CRUD API for managing a to-do list, built with FastAPI as part of FlyRank's Backend AI Engineering internship (Week 2, Assignment BE-01).

Data is stored in memory (a Python list) — it resets whenever the server restarts. No database yet.

## Tech Stack

- Python 3.10+
- FastAPI
- Uvicorn (ASGI server)
- uv (dependency & environment management)

## How to Run

1. Clone this repo:
   ```bash
   git clone <your-repo-url>
   cd <your-repo-folder>
   ```

2. Install dependencies with uv:
   ```bash
   uv sync
   ```

3. Start the server:
   ```bash
   uv run fastapi dev main.py
   ```

4. The API will be running at `http://localhost:8000`

## Endpoints

| Method | Path             | Description                          | Success Status | Error Status |
|--------|------------------|---------------------------------------|-----------------|--------------|
| GET    | `/`              | API info (name, version, endpoints)   | 200             | —            |
| GET    | `/health`        | Health check                          | 200             | —            |
| GET    | `/tasks`         | List all tasks                        | 200             | —            |
| GET    | `/tasks/{id}`    | Get a single task by id               | 200             | 404          |
| POST   | `/tasks`         | Create a new task                     | 201             | 400          |
| PUT    | `/tasks/{id}`    | Replace a task's title and done status| 200             | 400, 404     |
| DELETE | `/tasks/{id}`    | Delete a task                         | 204             | 404          |

### Request/Response Examples

**POST /tasks**
Request body:
```json
{ "title": "Buy milk" }
```
Response (201):
```json
{ "id": 4, "title": "Buy milk", "done": false }
```

**PUT /tasks/{id}**
Request body:
```json
{ "title": "Buy bread", "done": true }
```
Response (200):
```json
{ "id": 1, "title": "Buy bread", "done": true }
```
